# Compare UI options

Use when the owner asks for options or accepts an offer to compare them. Inspect the current CircuitLab UI and keep the learning goal, feature requirements, and sample circuit content consistent across options.

Create five numbered, credible approaches unless the owner requests another count. Vary layout, hierarchy, or learning workflow, not just colors. Keep labels useful to the task. Show a working example for each option plus its strengths, limits, best fit, effort, and accessibility concerns.

Save a standalone, dependency-free preview at `ui-previews/<feature-slug>.html`. Serve it locally and check wide and narrow layouts, interactions, focus, clipping, and browser errors. Confirm Git ignores the preview.

Share the clickable preview URL and ask the owner to choose or revise an option. Keep the preview server running during review, then stop it. Use the chosen option to guide implementation; do not implement before selection.
