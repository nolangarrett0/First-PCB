First PCB v0.3.1 improves the beginner experience, lesson sequence, diagrams, and practice controls.

Changes:

- Symbols and series connections now come before capacitors, transistors, and chips. Early lessons explain new terms when they appear.
- Start/resume controls work on phone and desktop layouts, and the full lesson row opens the activity.
- Worked examples show solved choices, calculations, sequences, and selected points. Practice help opens a different solved case.
- Circuit connections, breadboard jumper paths, switch selection, PCB labels, and layer explanations are clearer and more accurate.
- Number-entry guidance, correction feedback, keyboard controls, repeated-test selections, glossary search, and dialog scrolling are improved.
- Existing lesson identities, saved progress, notes, and backup compatibility are preserved.

Download `First-PCB-0.3.1-portable.exe` for Windows x64. Run it directly; no installer is required.

Validation: lint, production build, course contracts, twelve learning tests, all 77 activities, all 65 lesson readings, 430 diagram views, recovery scenarios, the Electron runtime, and the Windows portable build. See the [polish review](https://github.com/nolangarrett0/First-PCB/blob/v0.3.1/docs/polish-review.md) and its verification record.

The course remains a public beta. Physical work is optional and self-reported; the supplied diagrams and measurements are teaching models.
