First PCB v0.3.0 introduces electronics basics before the PCB project and makes the existing lessons easier to follow.

Changes:
- Nine opening lessons teach circuits, voltage/current, resistors, diodes/LEDs, capacitors, transistors, chips, drawing labels, and series/parallel connections. Each includes diagrams and practice with feedback.
- All 56 existing lesson procedures were rewritten with explicit component names, endpoints, and actions. The app now displays the main lesson explanation before the instructions.
- Worked-example text and diagrams describe the same case. Calculation feedback shows arithmetic and unit conversions; redundant label expansions and unclear wording were corrected.
- The course now has 65 lessons, eleven integrated unit checks, and a six-task final review. Existing lesson/check identities, notes, completions, and backup compatibility are preserved.
- New primary teaching and manufacturer sources are linked with the lessons. All 33 source links work in the desktop app.

Download `First-PCB-0.3.0-portable.exe` and run it on Windows x64. No installer is required. Existing local records are preserved; backups can be exported from the app.

Validation: lint, production build, course contracts, twelve learning tests, all 77 activity routes, all 65 lesson-reading checks, recovery scenarios, the actual Electron runtime, and the Windows portable build.

This remains a public beta of the conceptual course. The app's drawings and supplied observations are teaching models; it does not supply a physically validated PCB or order-ready parts list. See the [beginner course review](https://github.com/nolangarrett0/First-PCB/blob/v0.3.0/docs/beginner-course-review.md) for findings, sources, and verification.
