First PCB v0.2.0 expands the course with practice that uses circuit evidence and explains the labels beginners encounter.

Changes:
- 56 lessons, ten integrated unit checks, and a six-task final review now use connection selection, calculations with units, datasheet extraction, layer inspection, ordered procedures, and staged fault diagnosis.
- Corrective feedback leads to changed practice cases. Learning records distinguish fresh correct answers from supported and repeated work, with spaced review suggestions.
- Component, pin, connection, meter, and tool abbreviations have plain names and visible explanations throughout lessons and practice. A searchable project/glossary reference supports later lookup.
- Exact activity resume, legacy-progress migration, JSON backups, explicit storage-failure recovery, and native desktop close handling preserve learning work.

Download `First-PCB-0.2.0-portable.exe` and run it on Windows x64. No installer is required. The executable is not digitally signed. Existing local progress is preserved and migrated; backups can be exported from the app.

Validation: lint, production build, course contracts, ten learning tests, all 67 activity routes, all 56 lesson-reading checks, recovery scenarios, the actual Electron runtime, and the Windows portable build.

This is a public beta of the conceptual course. A beginner pilot and observed KiCad walkthrough remain to be done. The app does not supply a physically validated PCB or an order-ready parts list; its example drawings and observations are teaching models.
